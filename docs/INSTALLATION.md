# Установка NetPulse 0.6.13

Скачивайте файлы из [официального выпуска](https://github.com/yburylov/NetPulse/releases/tag/v0.6.13). SHA-256 каждого установочного файла приведена в `SHA256.txt`.

## Windows

1. Скачайте `NetPulse_0.6.13_x64-setup.exe`.
2. Запустите установщик, выберите RU/EN, способ установки и папку.
3. При обновлении устанавливайте поверх имеющейся версии, сохраняя профили.

Поддерживаются Windows 10/11 x64. Установщик не имеет доверенной цифровой подписи издателя: предупреждение Windows возможно. Сверяйте источник загрузки и контрольную сумму; не отключайте защиту системы ради установки.

При повторном запуске уже работающей программы должно открываться существующее окно. Если версия 0.6.13 уже установлена, свежая пересборка с тем же номером устанавливается вручную. Последующие версии проверяются через официальный публичный выпуск, наличие исходников для этого не требуется.

## Android

1. Скачайте `NetPulse_0.6.13_android.apk` на телефон.
2. Разрешите установку APK только тому приложению, из которого открываете этот файл, если Android запросит разрешение.
3. Установите поверх прежнего NetPulse. Не удаляйте данные приложения для обычного обновления.
4. Разрешите уведомления, если они нужны. Фоновый мониторинг включается отдельно в NetPulse.

Требования: Android 8.0+ и актуальный Android System WebView. Версия приложения 0.6.13, внутренний номер сборки 61302. Сохранена прежняя подпись для обновления поверх существующего приложения.

## iPhone / iPad

`NetPulse_0.6.13_ios-61301-unsigned.ipa` — сборка arm64 для реального устройства с iOS 17+, **без подписи**. Для установки её необходимо подписать вашим способом личного тестирования. Одного копирования файла по USB недостаточно.

Срок действия, доверие разработчику, необходимость режима разработчика и повторная подпись зависят от выбранного способа установки и учётной записи Apple. Не передавайте пароль Apple или сертификаты в Issues. При обновлении используйте прежний идентификатор приложения и подходящую подпись, чтобы сохранить данные. Выпуск не распространяется через App Store или TestFlight.

## Подключение к роутеру

Для чтения данных требуется SSH-доступ к OpenWrt / RouteRich. По умолчанию используется порт 22: запись `адрес:22` означает адрес и SSH-порт, а не другой IP-адрес.

В домашней сети используйте LAN-адрес. Вне дома необходим работающий Tailscale с доступом к роутеру или маршрутом его подсети. Управляющий ключ RemoteRouteRich нужен для соответствующих функций панели Tailnet, а не для обычного SSH-входа.

При изменении SSH-отпечатка сначала выясните причину. Не подтверждайте новый ключ вслепую и не отправляйте пароли в сообщения об ошибках.
